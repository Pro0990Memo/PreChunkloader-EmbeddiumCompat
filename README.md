# PreChunkloader-EmbeddiumCompat
1.20.1 Forge 47.4.10 mod for Force Pre-loading chunks in a changable radius. 
It can be used to make the game update the nearby chunks when they fail to load visibly. 
Using this in big modpacks is really helpful.
Compatable with Embeddium :)

The default key for pre-load is "P" but it can be changed from "Options\Controls\Key Binds\Chunk Preloader" in game.
The default radius for preloading is "8" but you can also change this from "Options\Video Settings\Chunk Preloader".
